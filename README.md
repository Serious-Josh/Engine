# Engine
Engine is an in development game engine. The goal is to make an actually usable engine with as advanced features as is fun to experiment with and implement. Features listed here:

- Deferrer Rendering
- Bindless Texturing
- PBR
    - Standard Metallic/Roughness
    - Complex n/k IOR complient materials
        - Dielectrics
        - Conductors
- RayTracing
    - RT soft shadows
    - RT reflections
    - RTGI
    - RTAO

Future goals listed here:

- Expanded material system
- Mesh Shading System
- Multi-threaded rendering
- ReSTIR Path Tracing
